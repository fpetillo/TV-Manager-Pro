# Flow Audit v18.3.0

The Version 18 navigation already groups TV Manager into the major daily workflows:

- Command Center
- Library
- Discovery & Search
- Processing
- Setup & Migration
- Administration

v18.3.0 adds Help Center navigation and workflow guidance to make those areas easier to understand.

## Recommended daily path

1. Launchpad — check readiness and next actions.
2. Show Queue — identify missing/wanted work.
3. Show Detail — review episodes, ignored rules, and search actions.
4. Download Center — validate handoffs and downloader status.
5. Post Processing — preview completed downloads before moving/renaming.
6. Jobs — monitor long-running actions.
7. Logs — review errors and audit trail.
8. Database Safety — back up before major changes.

## Cohesion checks added

- Help Center added to navigation and footer.
- Feature parity matrix maps SickChill concepts to TV Manager locations.
- Workflow map shows start screen and next step for common operator tasks.
- Troubleshooting guide points users toward Jobs, Logs, System, and Database Safety.
