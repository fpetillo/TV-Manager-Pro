# TV Manager v17.21.0 Release Notes

## Focus

Episode-search navigation polish for the show detail workflow.

## Added

- Automatic return to the episode list after a search result is successfully sent to the downloader.
- Episode list position/context preservation across the episode-search modal.
- **Back to Episodes** button in the search modal header and result actions.
- Show Detail quick links to Download Center and Active Jobs.

## Fixed

- Operators no longer lose their place after queueing a download from episode search results.
- The search modal no longer feels like a dead end after an episode is selected and sent to the download queue.
