# TV Manager 11.0 Release Notes

- Season-pack results can now be submitted to the configured NZB/torrent client.
- Wanted/failed missing episodes in a grabbed season are marked Snatched without touching episodes that already have media.
- Added opt-in API token enforcement.
- Added one-time token generation and hashed token storage.
- Added unit-test suite and PowerShell validation command.
- Added GitHub Actions CI workflow.
- Added comprehensive architecture, feature, migration, operations, security, API and roadmap documentation.
