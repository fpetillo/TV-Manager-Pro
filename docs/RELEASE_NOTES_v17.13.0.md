# TV Manager v17.13.0 - Show Queue Drill-Down

## Added

- Dedicated `/show/<show_id>` page.
- Show Queue title links now open the selected show's episode command center.
- Episode search, season filter, status filter, paging, and sortable episode table.
- One-click episode search/download workflow from the show detail page.
- Paged/filterable episode API mode for large shows.

## Fixed / Improved

- The Show Queue now behaves as a command center instead of only a reporting grid.
- Operators can move from all-shows view to episode-level action without jumping through the classic Library panel.
