# TV Manager v17.5.0 - Launchpad Experience

v17.5.0 adds a premium Launchpad experience designed to make TV Manager feel like a professional replacement system.

## Added

- `/launchpad` operator home screen.
- `/api/launchpad/summary` next-action API.
- Replacement readiness score.
- Action cards for import, health, configuration and cutover.
- Launchpad statistics for shows, episodes, imports, missing files, duplicates, folder gaps and metadata gaps.
- Product experience documentation.
- Cohesive navigation link to Launchpad across major pages.

## Validation

The test suite verifies the Launchpad routes, template, JavaScript, CSS and product experience documentation.
