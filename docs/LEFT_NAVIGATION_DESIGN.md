# Left Navigation Design

TV Manager v17.7.0 moves from a crowded horizontal top menu to a categorized left sidebar.

## Categories

- Command: Launchpad, Workflow Cockpit, Setup Assistant, Dashboard
- Library: Shows, Library Health, Upcoming, Missing
- Acquisition: Queue, Upgrades, Subtitles, Post Processing
- Migration: SickChill Import, Operations, Quality Profiles, Advanced
- Platform: Settings, System, Routes, Build Info, About

## Design Goals

- Keep every major feature visible without horizontal scrolling.
- Group actions by operator intent.
- Make SickChill migration and cutover feel guided.
- Preserve responsive behavior on tablets and smaller screens.
