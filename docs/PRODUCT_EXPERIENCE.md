# TV Manager Product Experience

TV Manager is being shaped as a complete SickChill replacement, not just a clone. The v17.5 experience centers the operator around clear next actions.

## Launchpad

The Launchpad is the recommended home screen for day-to-day use. It answers:

- Is the replacement ready?
- Did the SickChill import populate the active database?
- What health findings need attention?
- What should the operator do next?

## Workflow principles

1. **No blind destructive actions.** Risky work must have analyze, preview, apply, and audit stages.
2. **Health before cutover.** SickChill should not be stopped until the imported library is visible and Library Health is reviewed.
3. **Operator language.** Screens should say what to do next instead of exposing raw internals first.
4. **Version visible everywhere.** Every support screenshot should reveal the running build.
5. **Server replacement ready.** Install, backup, import, validate, cutover and rollback instructions live with the product.

## Recommended user journey

1. Open `/launchpad`.
2. Run SickChill Analyze and Preview in Import Center.
3. Import with the progress bar.
4. Verify Shows and Library Health.
5. Configure automation, naming, quality, subtitles and backups.
6. Run side-by-side, then cut over.
