# TV Manager v17.6.0 - Setup Assistant and Cutover Polish

v17.6.0 adds a guided Setup Assistant that helps operators finish the SickChill replacement workflow in the correct order.

## Highlights

- New `/setup-assistant` page.
- New `/api/setup/summary` endpoint.
- Guided install/import/health/configure/cutover checklist.
- Cutover readiness status and blocker list.
- New `docs/SICKCHILL_CUTOVER_CHECKLIST.md`.
- Navigation now includes Setup across the major product screens.
- Additional tests for the setup assistant and cutover package assets.
