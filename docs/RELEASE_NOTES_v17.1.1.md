# TV Manager v17.1.1 Release Notes

## Visible version and About page

This maintenance release makes the installed build easy to identify from the browser UI.

### Added

- Global footer showing `TV Manager v17.1.1` on application pages.
- New `/about` page with product, version, runtime and support-checklist information.
- New `/api/version` endpoint returning product/version/build metadata.
- System page now displays the running version from the `VERSION` file instead of a hard-coded value.

### Validation

- Full test suite updated and passing.
