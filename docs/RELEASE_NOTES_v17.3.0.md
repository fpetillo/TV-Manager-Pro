# TV Manager v17.3.0 Release Notes

## Product experience refresh

TV Manager v17.3.0 focuses on making the application feel like a cohesive professional replacement for SickChill rather than a collection of utility pages.

### Highlights

- Professional visual refresh across the application shell.
- Cohesive cards, panels, navigation, buttons, tables and empty states.
- Active navigation highlighting so operators always know where they are.
- Product hero sections on the Dashboard, Shows, Import Center, Library Health and About pages.
- Stronger visual language around safe migration, safe cleanup and local-first operations.
- Version remains visible in the global footer and About/System pages.

### Validation

- Full Python test suite remains passing.
- JavaScript syntax checks remain passing.
- Packaging excludes runtime databases, logs, caches, diagnostics and zip artifacts.
