# Version 18 Readiness

Version 18 formalizes TV Manager as a professional SickChill replacement readiness line.

The Version 18 checklist verifies these installation expectations:

- progress indicators and Active Jobs coverage for long-running work;
- Operations scan actions converted to background jobs;
- Show Queue sorting uses real numeric/date values, not display text;
- Download Center monitors downloader readiness, polling, and handoffs;
- database safety and lock protection are present;
- media server maintenance supports add, edit, delete, test, refresh, and sync actions;
- local GitHub release automation is included;
- Version 18 release documentation is installed.

Launchpad now shows a Version 18 polish checklist so gaps are visible from the first screen.
